# Mục lục trình bày Chương 2 - Phần 1

Thứ tự tài liệu khớp với notebook `Bai_thuc_hanh_chuong_2.ipynb`:

| Phần trình bày | Nội dung | Tài liệu |
|---|---|---|
| I | Toán tử điểm ảnh | `CHUONG_1_TOAN_TU_DIEM_ANH.md` |
| II | Lọc tuyến tính | `CHUONG_2_LOC_TUYEN_TINH.md` |
| III | Bài tập nâng cao | `CHUONG_3_BAI_TAP_NANG_CAO.md` |

Trong mỗi câu nên trình bày theo thứ tự:

1. Mục tiêu.
2. Input.
3. Nguyên lý hoặc công thức.
4. Code chính.
5. Hình ảnh output.
6. Nhận xét.

Tên file còn giữ chữ `CHUONG` để tránh làm hỏng liên kết cũ, nhưng tiêu đề
trong tài liệu đã được chuẩn hóa thành Phần I, II và III.
