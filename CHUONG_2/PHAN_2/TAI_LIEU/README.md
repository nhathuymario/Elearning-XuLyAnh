# Mục lục trình bày Chương 2 - Phần 2

Thứ tự dưới đây khớp với ba notebook thuyết trình I, II và III:

| Phần trình bày | Nội dung | Tài liệu |
|---|---|---|
| I | Lý thuyết Canny | `CHUONG_1_NEN_TANG_CANNY.md` |
| II.1-II.3 | Thực hành và thay đổi tham số | `CHUONG_2_THUC_HANH_CANNY.md` |
| II.4 | Canny, morphology, contour và hình dạng | `CHUONG_3_CONTOUR_VA_NHAN_DANG.md` |
| III | Các câu hỏi mở rộng | `CHUONG_4_MO_RONG_VA_HOAN_THIEN.md` |

`PLAN_CHUONG_2_PHAN_2.md` là tài liệu tổng hợp chi tiết để tra cứu. Khi
thuyết trình, nên đi theo thứ tự I-II-III trong bảng trên.

Mỗi câu nên có:

1. Mục tiêu hoặc câu hỏi.
2. Nguyên lý.
3. Code chính.
4. Hình ảnh kết quả.
5. Nhận xét và kết luận ngắn.

Phần II đã lưu đầy đủ ảnh so sánh tham số, loại ảnh, phân đoạn và nhận dạng.
Phần I và phần III vẫn có một số kết quả mở rộng cần bổ sung.
